# Antigravity Demo Web 🚀

Proyek web interaktif sederhana yang dibuat menggunakan Google Antigravity.

## Fitur
- 🌓 Dark / Light Mode Toggle
- ⚡ Animasi dan Glassmorphism modern
- 🔢 Counter interaktif dengan Vanilla JavaScript
- 📱 Responsif di semua ukuran layar

## Cara Menjalankan
Cukup buka file `index.html` di browser favorit Anda, atau gunakan live server.
